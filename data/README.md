# Historical textbook data

`cm1.csv` is the original 37-observation CM1 series, June 1986 through June 1989. Columns are ISO month, integer time index t (June 1986 = 1), and CM1 in percent. The chapter-8 notebooks continue to use this file.

`mortgage_indices.csv` transcribes all six series in Table 8.1 of the supplied fourth-edition textbook (PDF file page 275): TB3, TB6, CM1, CM2, CM3 and CM5. The source values have two decimal places and are percentages, not decimal fractions. The CM1 column and dates match `cm1.csv` exactly.

These are historical data for reproducing a textbook example. They are not live interest rates, a current forecast, or investment advice. The source table was read from native PDF text, and a page render was generated for inspection; no OCR was used.
