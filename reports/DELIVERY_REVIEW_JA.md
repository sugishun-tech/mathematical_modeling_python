## 主な修正

本編9冊を、英語の問題文、条件・単位、解法、実装、検算、結果の解釈という構成に改めました。以前未収録だった例題の中心モデルを追加し、問題文と教科書のPDFページを対応付けています。

農地の整数計画では120エーカー区画の誤った係数を訂正しました。全列挙・MILP・教育用の分枝限定法が一致する最適値は162,250ドルで、連続緩和162,500ドルとの差は250ドルです。椅子生産モデルは元の定義域で大域的に上に非有界であるため、内部の停留点を大域的最適解と呼ばないようにしました。

可変風速は街を過ぎた後に減速する教科書の区分式へ修正しました。トリチウムの総放射能、空間幅で割った濃度、仮定した閾値を区別し、実際の安全基準を検証した結果とはしていません。確率モデルでは初期値の添字、観測打ち切り、モンテカルロ誤差、予測期間に応じたAR(1)の分散を明示しています。

Newton反復、Euler法、同時状態更新、制約・整数性検査、定常分布、確率区間、粒子追跡などは `modeling/` の共通モジュールへ整理しました。notebookはそのモジュールを使用します。更新履歴は `CHANGELOG.md` に統一しています。

## 網羅性の限界

**教科書全体の全計算・全演習を検証し終えた版ではありません。** 44の番号付き例題について中心モデルの実装と検算を用意しましたが、各例題に付随するすべての感度分析・頑健性分析・図・式の独立検証までは実施していません。

章末演習164問は元の英語の問題文を画像としてnotebookに埋め込んだものです。文字式を推測して転記せず原版の組版を保っていますが、検索可能な数式テキストや解答集ではありません。選択した参照図表は追加していますが、本文全体・全参照先を複製したものでもありません。

演習別冊は提供された教科書由来の内容を含むため、プロジェクト独自部分のMITライセンスの対象外として分離しています。公開配布の許諾を確認したものではありません。本体ZIPに元PDF・原版ページ画像・Git履歴・フォントファイルは入れていません。

## 再現用コマンド

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
python run_all.py
python run_all.py --validate-only
python scripts/audit_project.py
jupyter lab
```

検証環境は `reports/tested_environment.json`、実行結果は `reports/execution.json`、単体テストは `reports/unit-tests.xml`、対応表は `COVERAGE.md` と `reports/coverage.csv`、修正根拠は `ERRATA.md` を参照してください。GitHub Actionsの設定は同梱していますが、GitHub側での実行は行っていません。
