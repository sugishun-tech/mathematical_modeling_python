Example 3.1: A pig with exponential weight growth

Source: textbook PDF pp. 65–73.

Problem statement

A pig weighs 200 lb at time zero and its weight follows . Price is dollars/lb and keeping cost is USD 0.45/day. Maximize incremental sale proceeds over . Locate a promising region on a graph, use Newton's method on the profit derivative, and independently verify the stationary point and endpoints.

Approach and verification

Use a bracketed root method as a reference and Newton iteration as the educational algorithm. Inspect residuals, not just successive changes in the decision. Then check the sign of the second derivative and compare all feasible candidates with both endpoints.

Python · cell 4 · execution 2
from scipy.optimize import brentq

from modeling.optimization import newton_scalar

profit = lambda t: 200 * np.exp(0.025 * t) * (0.65 - 0.01 * t) - 0.45 * t

derivative = lambda t: 200 * np.exp(0.025 * t) * (0.025 * (0.65 - 0.01 * t) - 0.01) - 0.45

optimum = float(newton.root[0])

Example 3.2: Locating a fire station

Source: textbook PDF pp. 74–78.

Problem statement

A town occupies miles. Approximate annual calls by nine point locations: , with frequencies . A call miles away takes minutes to reach. Find a location minimizing the weighted mean response time.

Compare a reproducible random search with local refinement. The fractional distance exponent makes the function nonsmooth at customer centers. A successful local solver is not a global-optimality certificate; explicitly compare all centers and multiple starting points.

Approach and verification

Aggregate calls into weighted demand points and minimize weighted response time. Random search gives starting locations; local refinement and explicit evaluation at demand centers check plausible alternatives. Distance raised to a power below one is not differentiable at a demand center, so a smooth-gradient argument needs care.

Python · cell 9 · execution 4
from scipy.optimize import minimize

centers = np.array([(1, 5), (3, 5), (5, 5), (1, 3), (3, 3), (5, 3), (1, 1), (3, 1), (5, 1)], float)

weights = np.array([6, 8, 8, 21, 6, 3, 18, 8, 6], float)

def response(point):
    distances = np.linalg.norm(centers - np.asarray(point), axis=1)
    return 3.2 + 1.7 * np.dot(weights, distances ** 0.91) / weights.sum()

locations = np.random.default_rng(302).uniform(0, 6, (5000, 2))

random_values = np.array([response(p) for p in locations])

random_best = locations[random_values.argmin()]

starts = np.vstack([centers, [[0, 0], [0, 6], [6, 0], [6, 6], [3, 3]], random_best])

results = [minimize(response, s, method='Nelder-Mead', bounds=[(0, 6), (0, 6)], options={'maxiter': 4000, 'xatol': 1e-08, 'fatol': 1e-10}) for s in starts]

assert all((r.success for r in results))

best = min(results, key=lambda r: r.fun)

assert best.fun <= min((response(p) for p in centers)) + 1e-08

assert 6 < best.fun < 7

print('Multi-start candidate (miles), response (minutes):', best.x, best.fun)

print('This is not a certified global minimum; fractional distance powers are nonsmooth at demand centers.')

Example 3.3: Lawn-chair production and a misleading global claim

Source: textbook PDF pp. 78–82.

Problem statement

A manufacturer makes wooden chairs and aluminum chairs per day. Costs are USD 18 and USD 10 per chair. Unit selling prices are and dollars. Find and classify the stationary production plan near using multivariable Newton iteration.

Also investigate whether the stated positive domain admits a global maximum. Do not infer global optimality merely from a contour plot or a negative-definite Hessian at one point.

Approach and verification

Newton iteration is applied to the profit gradient, with the Hessian as its Jacobian. Damping prevents steps outside the positive domain and requires a smaller residual. Test the Hessian at the stationary point. Separately inspect what happens near the domain boundary.

Python · cell 14 · execution 6
from modeling.optimization import newton_system

x, y = sp.symbols('x y', positive=True)

P = x * (10 + 31 * x ** (-sp.Rational(1, 2)) + sp.Rational(13, 10) * y ** (-sp.Rational(1, 5))) - 18 * x + y * (5 + 15 * y ** (-sp.Rational(2, 5)) + sp.Rational(4, 5) * x ** (-sp.Rational(2, 25))) - 10 * y

gradient = sp.Matrix([sp.diff(P, x), sp.diff(P, y)])

H = sp.hessian(P, (x, y))

pf = sp.lambdify((x, y), P, 'numpy')

gf = sp.lambdify((x, y), gradient, 'numpy')

hf = sp.lambdify((x, y), H, 'numpy')

result = newton_system(lambda p: np.array(gf(*p)).ravel(), lambda p: hf(*p), [5.0, 5.0], domain=lambda p: bool(np.all(p > 0)))

point = result.root

value = pf(*point)

assert np.all(np.linalg.eigvalsh(hf(*point)) < 0) and np.linalg.norm(gf(*point)) < 1e-08

print('Strict local maximum:', point, value)

near_axis = np.array([0.01, 1e-06, 1e-12, 1e-20])

near_values = pf(5, near_axis)

assert near_values[-1] > 1000 * value

display(pd.DataFrame({'fixed x': 5.0, 'y approaching zero': near_axis, 'profit': near_values}))

Interpretation and limits

The stationary point near (4.69, 5.85) is a local maximum. The stated model is unbounded as a production quantity approaches zero because a cross-price term diverges. It therefore has no global maximum on the full positive quadrant. A credible minimum production level or another demand model is needed before claiming a global production recommendation.

Example 3.4: Crop allocation with continuous acreage

Source: textbook PDF pp. 83–92.

Problem statement

A farm has 625 acres, 1,000 acre-ft of irrigation water and 300 person-hours/week of labor. Corn, wheat and oats use respectively acre-ft/acre and person-hours/week per acre. Their yields are dollars/acre. Choose nonnegative acreage to maximize yield subject to all resource limits.

Find all tied optimal plans along the optimal edge and interpret resource shadow prices. An optimizer may return either endpoint; do not hard-code one as the unique answer.

Approach and verification

Write one resource row for water, labor and land. SciPy minimizes, so maximize revenue by negating its coefficients. Check primal feasibility and objective value. For this example the entire edge joining two corner solutions is optimal, which explains why different solvers can return different crop mixtures.

Example 3.5: Transporting excavation material

Source: textbook PDF pp. 90–98.

Problem statement

Daily excavation supplies at sites 1–3 are at most 150, 400 and 325 cubic yards. Destinations A–D need at least 175, 125, 225 and 450 cubic yards/day. Site 4 has unlimited material costing USD 5/cubic yard. Hauling costs USD 20 per mile for a 10-cubic-yard load, modeled continuously as USD 2 per cubic-yard-mile. Distances are shown in the code table below.

Find a minimum-cost daily shipping plan. Unused excavated material is allowed; forcing every supply to be shipped changes the problem. Check the effect of one extra cubic yard at source 3 and ten extra cubic yards demanded at C.

Approach and verification

Make one nonnegative shipment variable per origin–destination pair. The purchased source has no supply cap but incurs both purchase and transport cost. Supply rows are upper bounds and demand rows are lower bounds. Check all row and column totals after optimization.

Python · cell 22 · execution 8
from scipy.optimize import linprog

miles = np.array([[5, 2, 6, 10], [4, 5, 7, 5], [7, 6, 4, 4], [9, 10, 6, 2]], float)

cost = 2 * miles

cost[3] += 5

supplies = np.array([150.0, 400.0, 325.0])

demands = np.array([175.0, 125.0, 225.0, 450.0])

source_rows = np.zeros((3, 16))

demand_rows = np.zeros((4, 16))

for i in range(3):
    source_rows[i, 4 * i:4 * i + 4] = 1

for j in range(4):
    demand_rows[j, j::4] = 1

A_transport = np.vstack([source_rows, -demand_rows])

def transport(supply=supplies, demand=demands):
    b = np.r_[supply, -demand]
    res = linprog(cost.ravel(), A_ub=A_transport, b_ub=b, bounds=(0, None), method='highs')
    return check_solution(res, A_ub=A_transport, b_ub=b, lower=0)

plan = transport()

assert np.isclose(plan.fun, 7650)

assert np.isclose(transport(supplies + [0, 0, 1]).fun, 7649)

assert np.isclose(transport(demand=demands + [0, 0, 10, 0]).fun, 7740)

display(pd.DataFrame(miles, index=[1, 2, 3, 4], columns=list('ABCD')))

display(pd.DataFrame(plan.x.reshape(4, 4), index=[1, 2, 3, 4], columns=list('ABCD')))

Example 3.6: Whole farm plots: corrected integer model

Source: textbook PDF pp. 99–106.

Problem statement

Replace continuous acreage in Example 3.4 by five 120-acre plots and one 25-acre plot. Each plot can be assigned to at most one crop, and all plot counts are integers. Keep water 1,000, labor 300 and the per-acre data from Example 3.4.

Derive every coefficient by multiplying its per-acre value by the actual plot size. The first printing incorrectly used 125-acre resource coefficients for the large plots; apply the author's official correction. Compare MILP, exhaustive enumeration and an educational LP branch-and-bound implementation. Compare the integer optimum with the relaxation of the same corrected model.

Approach and verification

Multiply per-acre requirements by 120 or 25 before constructing integer constraints. First solve the LP relaxation, then the MILP. Independently enumerate the small feasible integer set and run a transparent branch-and-bound implementation. These checks test different failure modes.

b_integer = np.array([1000, 300, 5, 1.0])

result = milp(-c_integer, integrality=np.ones(6), bounds=Bounds(np.zeros(6), np.full(6, np.inf)), constraints=LinearConstraint(A_integer, -np.inf, b_integer))

check_solution(result, A_ub=A_integer, b_ub=b_integer, lower=0, integral=True)

value, point, trace = branch_and_bound(c_integer, A_integer, b_integer, [5, 5, 5, 1, 1, 1])

feasible = []

for large in product(range(6), repeat=3):
    if sum(large) > 5:

Example 3.7: Assigning a limited fleet of larger trucks

Source: textbook PDF pp. 107–109.

Problem statement

The five routes in the book's truck-assignment table move cubic yards/day over miles. Small trucks carry 10 cubic yards and cost USD 20/mile/load; large trucks carry 20 and cost USD 30/mile/load. Corrected loading times are 20 and 30 minutes, unloading takes 5 minutes, speed is 20 mph, and a workday is 480 minutes. Use the table's one-way travel-time convention, with one truck type per route. Only three large trucks are available.

Compute integer load counts and truck requirements, then maximize daily savings using binary route decisions. Source discrepancy: Table 3.3 gives site 4 to D as 2 miles, while Table 3.5 uses 4. Reproduce the stated truck table, then report the alternative based on the transport table; do not silently combine the inconsistent distances.

Approach and verification

For each route, round the number of loads upward and calculate how many trucks are required within a working day. The binary decision chooses one truck type per route. Exhaustive enumeration of only 32 assignments is an independent and complete optimization check.

Python · cell 30 · execution 10
from modeling.optimization import binary_knapsack

miles = np.array([2, 4, 4, 4, 4.0])

volumes = np.array([125, 175, 225, 100, 350.0])

def inputs(distances):
    small_loads = np.ceil(volumes / 10)
    large_loads = np.ceil(volumes / 20)
    trips_per_large = np.floor(480 / (30 + 5 + 3 * distances))
    needs = np.ceil(large_loads / trips_per_large).astype(int)
    savings = 20 * distances * small_loads - 30 * distances * large_loads
    return (savings, needs)

savings, needs = inputs(miles)

assert np.array_equal(savings, [100, 360, 400, 200, 640])

assert np.array_equal(needs, [1, 1, 2, 1, 2])

value, choices = binary_knapsack(savings, needs, 3)

assert value == 1000

print('Best daily savings ($):', value, '; optimal route selections:', choices)

values = [binary_knapsack(savings, needs, k)[0] for k in range(1, 8)]

assert values == [360, 640, 1000, 1200, 1400, 1600, 1700]
