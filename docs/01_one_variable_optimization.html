Example 1.1: When should the pig be sold?

Source: textbook PDF pp. 12–24.

Problem statement

A pig currently weighs 200 lb and gains 5 lb/day. Keeping it costs USD 0.45/day. Its current sale price is USD 0.65/lb and is declining by USD 0.01/lb each day. Choose a nonnegative waiting time that maximizes sale proceeds minus future keeping costs. The purchase price is sunk and is not part of this incremental decision.

Use the five-step method: define the question; choose the model; formulate it; solve and check it; explain the decision. Weight and price are assumed linear over a credible short planning horizon. For a mathematical bound, restrict , so the linear sale price is not negative.

A stationary point is only a candidate. Compare it with the endpoints and check concavity. Predict whether the optimal decision or the maximum profit will be more sensitive to a small parameter change.

Approach and verification

Write down the feasible interval before differentiating. The marginal benefit of waiting is the change in weight times price, minus the loss caused by a falling price and the additional feed bill. Because the second derivative is negative, the interior stationary point is the unique maximizer when it lies in the interval. Otherwise the answer is an endpoint.

from scipy.optimize import minimize_scalar, brentq

from modeling.optimization import sensitivity

p0, r, w0, g, c = (0.65, 0.01, 200.0, 5.0, 0.45)

profit = lambda t: (p0 - r * np.asarray(t)) * (w0 + g * np.asarray(t)) - c * np.asarray(t)

optimum = np.clip((p0 * g - r * w0 - c) / (2 * r * g), 0, 65)

assert optimum == 8 and np.isclose(profit(optimum), 133.2)

assert profit(optimum) > max(profit(0), profit(65))

assert 2 * r * g > 0

opt_time = lambda rate: (p0 * g - rate * w0 - c) / (2 * rate * g)

assert np.isclose(sensitivity(opt_time, r), -3.5, atol=1e-06)

print('Sale-time elasticity to the rate of price decline:', sensitivity(opt_time, r))

print('Growth-rate elasticity:', sensitivity(lambda growth: (p0 * growth - r * w0 - c) / (2 * r * growth), g))

robust = lambda t: (p0 - r * np.asarray(t) + 4e-05 * np.asarray(t) ** 2) * (w0 + g * np.asarray(t)) - c * np.asarray(t)

roots = np.roots([0.0006, -0.084, 0.8])

candidates = np.array([0.0, 65.0, *[z for z in roots if np.isreal(z) and 0 <= z <= 65]])

choice = candidates[np.argmax(robust(candidates))]

check = minimize_scalar(lambda t: -robust(t), bounds=(0, 65), method='bounded')

assert check.success and np.isclose(check.x, choice, atol=0.0001)

print('Robust-model optimum (days, dollars):', choice, robust(choice))

print('The horizon matters: an upward-turning price polynomial is not credible indefinitely.')

Interpretation and limits

The linear model recommends waiting 8 days, producing USD 133.20 of proceeds net of future feed. This is not total lifetime accounting profit. The quadratic-price alternative moves the decision to about 10.28 days but changes the objective much less. That contrast separates decision sensitivity from value sensitivity. A polynomial price forecast should not be extrapolated indefinitely.
